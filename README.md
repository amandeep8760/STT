# 🚕 Sagar Tour and Travel - Web Application

A modern, professional, mobile-friendly tour and travel booking website for **Sagar Tour and Travel**.

## 🌟 Key Features

- **Fleet Showcase**: 5-Star Traveller, Maruti Ertiga, Mahindra Thar, Mitsubishi Pajero, Maruti Swift with passenger & luggage capacity.
- **WhatsApp Booking System**: Direct 1-click booking via WhatsApp (7901864610) with pre-filled trip details.
- **Online Booking Form**: Capture customer name, mobile, pickup, destination, travel date, time, passengers, vehicle, and trip type. Generates a unique Booking ID (`STT-2026-XXXX`).
- **Embedded Single-Page Admin Dashboard**: Access booking management, fleet updates, tour packages, services, reviews, and business settings directly on `http://127.0.0.1:5000/#admin`.
- **Tour Packages**: Pre-configured customizable tours (Himachal, Golden Triangle, Pilgrimage Dham, Wildlife Safari).
- **Responsive Mobile First Design**: Dark navy, white, and golden accent theme with glassmorphic cards and sticky navigation.

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.8+ installed on your system.

### 2. Installation & Setup
Clone the repository and install requirements:
```bash
git clone https://github.com/YOUR_USERNAME/sagar-tour-and-travel.git
cd sagar-tour-and-travel
pip install -r requirements.txt
```

### 3. Run Application
```bash
python app.py
```
Open your browser and visit:
- **Website**: `http://127.0.0.1:5000/`
- **Admin Panel**: Click **🔐 Admin** or visit `http://127.0.0.1:5000/#admin`
- **Default Admin Passcode**: `sagar123`
